# Nimbus API

Generated by `node bin/api-docs.mjs` from the route() calls in the server modules. All routes need a login
(session cookie) unless noted; changes must be sent as JSON. `/api/hook/*` routes are for bots during a run
(header `x-nimbus-hook`). `bin/nimbus.mjs <METHOD> <path> [json]` calls any of them from the server.
